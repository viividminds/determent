# Determent — Roads beyond the hearth

The expansion is deployed to https://tight-frost-35c6.certifiedcoal.workers.dev/.

The ZIP in downloads contains complete source, assets, docs, tests and Cloudflare configuration.

- T: skill tree; 2: learned class ability
- B: town forge and supplies; C: outfit palettes
- G: road board, with Cinder Orchard and Widow’s Ossuary
- One-turn NPC/foe dialogue, text reveal and speaker tones

Old checkpoints and original endings remain compatible. Gameplay, campaign, expansion, audio and desktop/touch checks passed. Cloudflare confirms the version at 100% traffic. Human playtesting remains useful for difficulty and sound balance.

For a local deployment of this backup, extract it and run `wrangler deploy --config wrangler.jsonc` from the extracted folder with your existing Cloudflare login.
